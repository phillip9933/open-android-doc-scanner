# Scanner refinements - 0.1.0-rc4

The standalone camera now fills the upper screen behind the status bar. Its overlay controls respect the status inset, and its lower controls have more padding above the navigation area. PreviewView uses FILL_CENTER; shared CameraX viewport mapping supports both centered fill and the existing centered fit mode. Hosts should enable edge-to-edge as the sample does. Status/navigation icon appearance is restored when the flow leaves composition.

The manual shutter is a single outlined disc, without the extra inner circle. A rotating arc surrounds the automatic scanning stop control only while the camera is ready and automatic scanning is active. It disappears when scanning is paused, capturing/importing, blocked by a dialog, unavailable, or at the page limit.

Review and save previews accept horizontal swipes and previous/next arrows. A completed swipe moves exactly one page; cancelled gestures leave selection unchanged. Gesture state includes the selected index and page order so it remains correct after reordering. Save keeps selection when returning to review, uses original vector PDF/JPG file badges, and has adjacent Back and Close controls on the left. Back returns to editing; Close asks before discarding the entire unsaved session.

The review back control and retake action ask before discarding the selected page and returning to capture. The next successful capture/import returns to review and inserts the replacement at that page's original position. Failed/cancelled capture leaves the confirmed discarded page removed; other pages remain intact. Leaving capture to review or choosing Add clears the pending replacement position. An intentional retake resets the successful-scene lock so the same document can be captured again. Trash asks before deleting the selected page; deleting the last page returns to capture. Cancelling either dialog preserves all pages.

Automatic capture continues to consume raw detector results. It may retain stability evidence across a same-scene, good-quality detection-only interruption of at most 250 ms; a missing current frame never triggers capture. It still requires 900 ms elapsed, at least four valid observations, at least 80% valid observations, and at least 630 ms of directly observed stable intervals. Intervals across missing corners receive no stable-time credit. Blur, bad exposure, invalid/low-confidence non-null corners, scene changes and excessive raw movement reset evidence. Missing display outlines still clear immediately. These rules improve tolerance to brief misses without using stale or smoothed corners to trigger a shutter.

The 52 camera tests and five core tests cover these temporal rules, original scene locks and centered fill mapping. End-to-end Android checks exercise page swipes after reorder, arrows, cancelled and confirmed retake/delete, replacement order, named two-page PDF output, Back/Close behavior, two consecutive manual captures, pause/resume feedback and typed cancellation/failure. Normal and 200% text checks use synthetic pages and the emulator camera. Physical handheld focus, crop accuracy, thermal performance and accessibility acceptance remain separate; see DEVICE-ACCEPTANCE.md and DETECTION-IMPROVEMENTS-RC4.md.
