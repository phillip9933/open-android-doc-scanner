# scanner-ocr-tesseract

Optional offline English/Japanese OCR adapter for consuming Android apps. Includes rebuilt Tesseract 5.5.3 with model-parser fixes and libpng 1.6.59, using bindings from Tesseract4Android 4.9.0. Apps install the approved English/Japanese models; hashes are verified before native loading. Does not add OCR to the sample app or change existing scan output.

See [integration, card layouts, models, limits and validation](../docs/OCR.md).
